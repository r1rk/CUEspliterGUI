# CUEspliterGUI

CUEシート（`.cue`）のタイムスタンプ情報に基づいて、1つの大型音声ファイル（FLAC、WAV、MP3など）をトラックごとに自動で分割し、メタデータ（ID3タグ / Vorbis Comment 等）を付与するデスクトップGUIアプリケーションです。

---

## 🌟 主な機能

- 🎵 **ドラッグ＆ドロップ対応**: CUEファイルや音源ファイルをアプリ上に直接ドロップして手軽に読み込み可能。
- 🔍 **CUEファイルの自動パース & 文字コード自動判別**: `chardet` を使用して日本語や異体字が含まれるCUEファイルのエンコーディングを自動判別。
- 🎧 **音源ファイルの自動推測**: CUEファイルを読み込むと、内部の `FILE` 記述や同一ディレクトリ内の同名音源ファイルを自動的に読み込み。
- 📋 **トラックプレビュー機能**: トラック番号、曲名、アーティスト、開始／終了時間を一覧テーブルで確認可能。
- ⚡ **無劣化高速分割 (Stream Copy)**: `ffmpeg` のストリームコピー機能（`-c copy`）を利用し、再エンコードなしで品質を維持したまま高速に切り出し。
- 🏷️ **メタデータ自動付与**: 切り出した音声ファイルにタイトル、アーティスト、アルバム名、トラック番号を自動設定。
- 📂 **出力先カスタマイズ**: CUEファイルと同じフォルダへの保存のほか、任意の出力先フォルダを指定可能。
- 🌙 **ダークモードUI**: 長時間の作業でも目に優しいダークテーマのグラフィカルインターフェース。

## 🛠️ 前提条件・動作環境

### 1. Python 環境
- **Python**: 3.8 以上

### 2. 外部依存ツール（必須）
- **FFmpeg**: 音声の切り出し・変換に `ffmpeg` を使用します。
  - システムの環境変数（`PATH`）に `ffmpeg` が通っている必要があります。
  - **Windowsでのインストール例**:
    - **winget (推奨)**: `winget install Gyan.FFmpeg`
    - Chocolatey: `choco install ffmpeg`
    - Scoop: `scoop install ffmpeg`
  - **macOSでのインストール例**:
    - Homebrew: `brew install ffmpeg`


## 🚀 使い方

### 1. アプリケーションの起動

スクリプトを実行してGUIを立ち上げます。

```bash
python cuesplitergui.py
```

### 2. 操作手順

1. **ファイルの読み込み**:
   - **CUE ファイル**: 「参照...」ボタンから選択するか、ウィンドウ内に `.cue` ファイルをドラッグ＆ドロップします。
   - **音源ファイル**: 通常はCUEファイル読み込み時に自動検出されますが、手動で「参照...」またはドラッグ＆ドロップで指定可能です（対応フォーマット: `.flac`, `.wav`, `.mp3`, `.ape`, `.m4a`, `.aac`, `.ogg`）。
2. **保存先の設定**:
   - デフォルトではCUEファイルと同じフォルダに保存されます。
   - 別のフォルダに保存したい場合は「カスタム出力先を指定する」にチェックを入れ、保存先フォルダを選択します。
3. **トラック情報の確認**:
   - 中央の「トラック一覧」テーブルで、読み込まれた曲名や分割時間を確認します。
4. **分割の実行**:
   - 「音声ファイルの分割を開始」ボタンを押します。
   - プログレスバーとログ出力エリアで処理の進捗を確認できます。
